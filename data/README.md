# India State and District Data

`india_states_districts.json` contains state and district names used by the authenticated property form. It is a maintained community dataset whose README identifies the Government of India IGOD state/district portal as its source. Review the source periodically when administrative boundaries change.

Source: https://github.com/KTBsomen/Indian-state-district-json (MIT licensed; data source cited there: https://igod.gov.in/sg/district/states).
